交互原则

  • 少描边：默认、悬停、选中、焦点都优先用背景层级表达，只有必要的结构轮廓可使用极弱内阴影。
  • 少套层：页面区块、面板、列表项各自独立，不在面板里继续制造多层卡片。
  • 密度稳定：工具栏、图标按钮、表格行、输入框使用固定高度，hover 不改变尺寸。
  • 颜色克制：红色只用于主操作、选中和错误；蓝/绿/黄用于信息、运行、编译/暂停等状态。
