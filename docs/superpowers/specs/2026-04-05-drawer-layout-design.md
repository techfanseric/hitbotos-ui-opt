# 动作编辑器 - 抽屉布局调整设计

日期：2026-04-05
状态：已实施

## 1. 变更概述

将代码/JSON 输出从独立模式改为右侧抽屉面板。

## 2. 布局变更

### 之前
- 工具栏：[Blockly] [流程图] [代码] | 编辑工具 | [生成代码]
- 主区域：三种模式切换显示

### 之后
- 工具栏：[Blockly] [流程图] | 编辑工具
- 主区域：编辑器 + 右侧可收起抽屉面板
  - Blockly 模式 → 抽屉内容：Python 代码（只读）
  - 流程图模式 → 抽屉内容：JSON 数据（只读）

## 3. 抽屉交互

- **触发**：编辑区右侧边缘有一个 20px 宽的轻量手柄，带竖排"源码"标签和展开箭头
- **展开/收起**：点击手柄切换抽屉显示状态
- **宽度调整**：拖拽手柄可改变抽屉宽度（最小 150px，最大 50%）
- **默认状态**：收起（仅显示手柄）

## 4. 数据流

- Blockly workspace 变化 → 实时生成 Python 代码 → 更新抽屉 CodeMirror
- JointJS graph 变化 → 实时生成 JSON → 更新抽屉 CodeMirror
- 抽屉内容只读，不可编辑

## 5. 代码/JSON 生成

- Blockly：每 500ms 轮询同步（因 `addChangeListener` 在当前 Blockly 版本不触发，改用定时轮询）
- 流程图：监听 graph 的 `change` 和 `remove` 事件
- 防抖处理：300ms debounce（仅流程图），Blockly 轮询间隔 500ms
