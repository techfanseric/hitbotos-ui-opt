# 已有明确思路的解决方案

> 基于 2026-03-01 和 2026-03-02 两次需求沟通会议，整理出已有明确解决思路的问题。

---

## 一、工具栏优化

### 现状问题

- 工具栏目前在页面内部，需要提取出来固定显示
- 用户无法随时访问工具功能

### 解决方案

**已确认方案**：

- 将工具栏提取出来，固定显示在窗口顶部
- 参考竞品功能：
  - 标签显示：可拖拽显示设备参数、价格、名称等信息
  - 测量工具：面到面、点到面、线到面的测量
  - 单位/间距：显示间距标准
  - 爆炸图：点击后从中心点炸开，便于查看内部结构

**优先级**：第一阶段

---

## 二、模型库侧边栏

### 现状问题

- 设备库平铺后会挡住后面的 3D 视图
- 用户一上来不知道设备库怎么用
- 拖进来后看不到，需要手动关闭

### 解决方案

**已确认方案**：

- 做成**侧边栏方式**
- 可以拖拽使用，不关闭
- 按类别展示，需要有分类体系
- 参考 AutoM8：外部设备 + 自有品牌分类
- 可做复合筛选功能

**优先级**：第一阶段

## 三、真机/仿真运行模式区分

### 现状问题

- 用户不清楚当前运行的是真机还是仿真
- 点击"运行"按钮时，3D 跟着走，但代码不会走
- 点击另一个按钮时，代码走，但 3D 不会走
- 给用户造成很大困惑

### 解决方案

**已确认方案**：

- 在播放按钮下方做一个下拉选择或复选框
- 让用户明确选择：真机模式 / 仿真模式
- 如果没有连接真机，该选项灰掉
- 参考 IDE 范式：Build + Run 模式
  - 发送 = Build（编译生成可执行文件）
  - 运行 = Run（选择目标运行）

**具体交互**：

- 设置两个勾选项：
  - 勾选1：真机运行（下载程序并运行）
  - 勾选2：仿真环境运行
- 至少勾选一个才能运行
- 顶部工具栏的演示播放按钮暂时去掉（因为有歧义）

**技术背景**：

- 真机和仿真运行的是同一套程序、同一套逻辑
- 区别在于：真机有机器 ID，仿真没有
- 真机参数更准，仿真参数可能偏一点
- 仿真主要给客户演示用，还没买设备的场景

**优先级**：第一阶段

## 四、夹取物品交互优化

### 现状问题

- 用户需要手动填写"夹取物品是哪个"
- 填写格式非常不直观：需要填编号如"第1个、第2个"
- 用户体验极差

### 解决方案

**已确认方向**：

- 考虑用**隐藏部件功能**：只显示当前操作的部件
- 建议用**矩阵/列表**方式选择要操作的物品
- 选中了夹爪和被夹物品后，自动识别关联
- 支持"遍历所有"或"选择前N个"等逻辑
- 吸附功能：点击吸附后，物体自动对齐

**优先级**：第二阶段

---

## 五、IO 状态仿真编辑

### 现状问题

- 真机上有各种 IO 传感器信号（开门信号、关门信号、检测结果等）
- 仿真时没有真实的传感器和信号
- 目前工程师需要手动在程序里加"仿真专用函数"
- 用户需要在仿真界面配置哪个动作要带哪个物品
- 找 ID、填 ID，交互非常不友好

### 解决方案

**已确认方向**：

- 考虑增加一类"真机不执行的函数"，只在仿真时运行
- 类似于程序里的 debug 或注释
- 让用户可以配置：
  - IO 信号触发的时间点
  - 信号之间的间隔
  - 是否需要随机等待
- 参考张建那边新控的传感器案例

**典型场景示例**：

- 抽屉开关：需要配置开抽屉信号、关抽屉信号
- 试剂检测：检测结果也是一个 IO 状态
- 设备初始化成功/失败都是状态

**优先级**：第二阶段

## 六、两级用户界面设计

### 设计思路

**背景**：

- 底层操作涉及非常原始和底层的细节（点位、机械臂、电机等）
- 终端用户（如做实验的人员）不需要关心这些细节

**解决方案**：

1. **底层界面**（对内/开发人员）：
   - 显示完整的底层操作细节
   - 包含点位、电机等原始操作
   - 方便开发人员使用

2. **暴露模块**（对外/终端用户）：
   - 通过触发模块暴露简化的操作
   - 只暴露几个关键参数给外部
   - 例如：版位来源、版位目标、输入框最大值/最小值

3. **上层界面**（实验流程）：
   - 用户先定义实验
   - 创建后以卡片形式展示
   - 提供删除、编辑、进入流程图等按钮
   - 可以直接运行，不需要关心内部细节

**优先级**：中期规划

---

## 七、实验流程卡片化展示

### 设计思路

**背景**：

- 用户需要一种更简单的实验流程管理方式
- 实验流程应该对终端用户友好

**解决方案**：

- 实验（如"分子组装"）以卡片形式展示
- 每张卡片包含：
  - 实验名称
  - 实验描述
  - 删除、编辑按钮
  - 进入流程图入口
- 用户点进去后可以直接运行
- 不需要关心内部实现细节

**优先级**：中期规划
